# Módulo 2 — Diseño de instrucciones contables

_Paquete didáctico base · 4 horas totales · 3 horas guiadas + 1 hora independiente · pendiente de adaptación a la matrícula._

---

## Propósito y alcance

Al finalizar, cada participante podrá redactar, probar y mejorar instrucciones para tareas contables acotadas, especificando **rol, contexto, tarea, datos permitidos, formato de salida y verificación**. Aprenderá a separar la calidad de una instrucción de la exactitud de una respuesta: un prompt mejor puede reducir ambigüedades, pero no garantiza que un sistema generativo produzca información correcta.[^1][^2][^3]

El material está diseñado para estudiantes y profesionales con conocimientos contables iniciales, sin requisito de programación. Esta es una base de trabajo; cuando se comparta la matrícula, se adaptarán vocabulario, ejemplos, ritmo y apoyos sin inferir características del grupo.

> **Privacidad:** las actividades usan movimientos inventados. No pegues datos de clientes, nómina, proveedores, cuentas bancarias, declaraciones ni capturas de sistemas internos en este cuaderno o en un asistente de IA.

## Ubicación y continuidad

Este es el segundo módulo del [plan de trabajo del curso](../plan-trabajo-curso-ia-contaduria.md). Se apoya en el Módulo 1 —[Fundamentos de IA y criterio profesional](../modulo-01/README.md)— y desarrolla de forma sistemática la práctica 1, **“Redacta un prompt contable útil”**, del [Laboratorio ContaIA](https://8328-i143dgisqzurgn5srq8gm-85c68042.us3.manus.computer/).

La práctica del laboratorio marca presencia de palabras clave de su rúbrica: no usa un modelo de IA ni determina por sí sola si un prompt es preciso, seguro o produce resultados correctos. Úsala como recordatorio para revisar seis elementos, no como certificación de calidad.

## Modalidad de práctica

No se requiere una cuenta de IA ni una conexión externa para impartir este módulo. Puede trabajarse con revisión entre pares y salidas impresas. Si la institución autoriza una herramienta generativa para demostración, utilizar únicamente el caso sintético y seguir las políticas internas; comprobar cada dato antes de usarlo.

## Referencias

Las recomendaciones generales de claridad, contexto, ejemplos, formato e iteración se contrastaron con guías de proveedores, que también advierten que las técnicas y resultados pueden variar entre modelos.[^1][^2] NIST describe el riesgo de salidas generadas falsas o erróneas que se presentan con seguridad; por ello, el curso requiere verificación independiente.[^3]
