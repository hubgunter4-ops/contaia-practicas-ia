# Fase 2 — Contexto continuo

La aplicación no recibe ni almacena documentos. La persona trabaja con sus propios archivos en la herramienta que elija y usa el sitio para seguir la guía de Nora. Para aprender de forma segura, prepara una copia de práctica y elimina datos personales o confidenciales antes de usar NotebookLM, Claude o n8n.

## Qué preparar

| Módulos | Documento o material | Debe contener | Formato sugerido |
|---|---|---|---|
| 1 | Descripción de una tarea | Objetivo, revisor y ejemplo ficticio de entrada | Texto, PDF o nota breve |
| 2 | Caso y rúbrica | Contexto, tarea, formato, límites y datos faltantes | Texto, PDF, XLSX o plantilla |
| 3 | Política o formato de nómina | Campos necesarios, propósito, acceso y aprobaciones | PDF, documento o tabla ficticia |
| 4 | Transacciones y catálogo | Fecha, concepto, importe y regla de categoría | CSV o XLSX |
| 5 | Banco y libro auxiliar | Fecha, referencia, importe y saldo del mismo periodo | Dos CSV/XLSX |
| 6 | Balanza | Cuenta, debe, haber o saldo, periodo y moneda | CSV, XLSX o tabla |
| 7 | Cifras para comunicar | Periodo, destinatario, fuentes y decisión esperada | PDF, documento, CSV o plantilla |
| 8 | Registro y línea base | Patrón, frecuencia, criterio de excepción y evidencia | CSV/XLSX más una nota |
| 9 | Fuente fiscal y caso hipotético | Ejercicio, régimen, jurisdicción, faltantes y fuente | Enlace/PDF oficial y ficha |
| 10 | Materiales anteriores y flujo | Entradas, salidas, validaciones, aprobador y escalamiento | Carpeta ficticia, diagrama o tabla |

## Preparación mínima antes de cada actividad

1. **Define el objetivo:** qué quieres aprender o comprobar.
2. **Identifica el periodo y la unidad:** por ejemplo, mes, ejercicio y moneda.
3. **Comprueba las columnas o secciones:** no trabajes con archivos sin encabezados o estructura.
4. **Marca los faltantes:** una celda vacía debe quedar como pendiente, no inventarse.
5. **Anonimiza:** reemplaza nombres, RFC, CURP, cuentas, domicilios, folios y cifras sensibles.
6. **Conserva la fuente:** anota de dónde salió cada cifra o regla.
7. **Usa una copia:** no trabajes directamente sobre el archivo original.

> Si no tienes documentos propios, utiliza los datos ficticios del laboratorio. No necesitas subir archivos a ContaIA para completar ninguna actividad.
