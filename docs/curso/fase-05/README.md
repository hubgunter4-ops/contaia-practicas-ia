# Fase 5 — Diagnóstico, ruta adaptativa y proyecto integrador

## Qué debe hacer la persona

1. Responder el diagnóstico inicial. No es un examen y no se guardan sus selecciones.
2. Leer la ruta que Nora recomienda: fundamentos, práctica guiada o proyecto integrador.
3. Trabajar los módulos sugeridos y consultar el glosario cuando aparezca un concepto nuevo.
4. Completar las cinco etapas del proyecto integrador con datos ficticios.
5. Abrir el diagnóstico final al cerrar el recorrido.
6. Comparar el resultado inicial y final para identificar qué reforzar.

La aplicación solo conserva, si el navegador lo permite, los resultados numéricos y las etapas marcadas como completadas. No conserva las respuestas elegidas, textos escritos, documentos ni conversaciones.

## Proyecto integrador

| Etapa | Pregunta que debe responder | Evidencia |
|---|---|---|
| 1. Preparar contexto | ¿Cuál es el caso, periodo, moneda y fuente? | Ficha y checklist de privacidad |
| 2. Diseñar la instrucción | ¿La petición define contexto, tarea, formato, límites y verificación? | Prompt revisado |
| 3. Analizar y separar | ¿Qué es hecho, hipótesis, pendiente o excepción? | Tabla con evidencia faltante |
| 4. Comunicar | ¿Qué debe saber la persona destinataria y cuál es el siguiente paso? | Reporte de una página |
| 5. Gobernar el flujo | ¿Qué validación, aprobación y escalamiento existen? | Diagrama o tabla del flujo |

## Puerta de decisión para IA remota

ContaIA permanece en modo local. La puerta de decisión se explica antes de conectar cualquier proveedor para que la persona entienda qué implicaría esa decisión. **Abrir la sección no activa ninguna conexión.**

Antes de aprobar una IA remota se tendría que definir y revisar:

- proveedor, modelo y región;
- datos prohibidos, retención y tratamiento;
- consentimiento visible antes de enviar texto;
- autenticación, presupuesto, límites y rate limiting;
- modo degradado hacia Nora local;
- seguridad, legalidad, pruebas de contrato y auditoría.

Mientras estos puntos no estén aprobados explícitamente, no hay endpoint, proveedor remoto ni envío de datos. Las actividades continúan con Nora local y datos ficticios.
