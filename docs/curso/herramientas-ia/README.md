# Herramientas de IA para el recorrido

Estas herramientas se integran como **prácticas opcionales**. El curso no requiere cuentas, API keys ni conexiones automáticas para completar las actividades.

## 1. NotebookLM / Gemini Notebook

- **Para qué sirve en el curso:** trabajar sobre fuentes proporcionadas, hacer preguntas sobre documentos y producir esquemas, resúmenes o materiales de estudio.
- **Actividad inicial:** cargar una guía educativa o un documento ficticio y preguntar qué significa un concepto antes de usarlo.
- **Regla:** revisar que la fuente sea pertinente y vigente; no subir información de clientes, empleados o expedientes reales.
- **Sitio oficial:** <https://notebooklm.google/?hl=es>

## 2. Claude

- **Para qué sirve en el curso:** practicar explicaciones sencillas, comparar versiones de un prompt, generar borradores y revisar una salida contra una rúbrica.
- **Actividad inicial:** pedir una explicación para una persona que nunca ha usado IA y señalar qué afirmaciones deben comprobarse.
- **Regla:** tratar la respuesta como borrador; verificar cálculos, fuentes, periodo, régimen y destinatario antes de compartirla.
- **Sitio oficial:** <https://claude.ai/>

## 3. n8n

- **Para qué sirve en el curso:** dibujar flujos de automatización, validar entradas, separar excepciones, solicitar aprobación humana y conservar trazabilidad.
- **Actividad inicial:** construir un flujo con datos ficticios que se detenga cuando faltan campos o aparece información sensible.
- **Regla:** no conectar sistemas productivos, credenciales reales, declaraciones, pagos ni notificaciones externas durante el aprendizaje.
- **Sitio oficial:** <https://n8n.io/>

## Secuencia recomendada

1. **NotebookLM:** entender el concepto usando fuentes controladas.
2. **Claude:** practicar una explicación o un borrador con límites explícitos.
3. **n8n:** convertir el procedimiento en un flujo con validaciones y revisión humana.
4. **Nora:** comparar el resultado con la evidencia, la rúbrica y el criterio profesional.

> Las actividades del sitio utilizan datos ficticios. La integración mostrada es educativa: no envía automáticamente los datos del laboratorio a estos servicios.
