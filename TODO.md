# Criterios del proyecto — Laboratorio ContaIA

- [x] Crear una página de inicio y navegación por módulos de aprendizaje inspirados en los enfoques didácticos de Alegra Academy, Edutin y ContadorMx, sin copiar contenido propietario.
- [x] Crear un laboratorio de prompts para contadores con consignas, campos de práctica, criterios de calidad y ejemplos de mejora.
- [x] Incluir ejercicios guiados de conciliación bancaria con movimientos ficticios, identificación de diferencias y explicación paso a paso.
- [x] Incluir prácticas de clasificación de transacciones contables con categorías, validación inmediata, pistas y justificación de respuestas.
- [x] Incluir módulos para analizar balanzas de comprobación y elaborar reportes contables a partir de conjuntos de datos ficticios.
- [x] Incluir ejercicios de análisis financiero y detección de anomalías mediante indicadores, patrones y escenarios simulados.
- [x] Incluir casos didácticos contextualizados para México sobre ISR, RESICO y nómina, presentados únicamente con datos ficticios.
- [x] Proveer retroalimentación educativa local con pistas progresivas, comprobación de respuestas y soluciones modelo, sin llamadas a servicios externos de IA.
- [x] Mostrar avisos visibles de que el contenido fiscal es educativo y no constituye asesoría; incluir pautas para no ingresar datos reales o confidenciales de clientes.
- [x] Entregar un repositorio con archivos fuente, ejercicios y datos ficticios, documentación técnica y guía de instalación y ejecución.
